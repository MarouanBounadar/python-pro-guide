   - **Chapitre 03** : Opérateurs, Expressions & Priorités (Arithmétique, Logique, Comparaison, Associativité de la puissance `**`, Évaluation court-circuit).
   - **Chapitre 04** : Structures Conditionnelles (if, elif, else, Facture d'eau progressive par tranches, Années bissextiles, Code PIN 4 chiffres).
   - **Chapitre 05** : Boucles & Itérations (for, while, range, break, continue, clause boucle-else, Factorielle $n!$, Optimisation de primalité $\sqrt{n}$).
   - **Chapitre 06** : Séquences & Structures Fondamentales (Listes dynamiques, Slicing avancé `[::-1]`, Mutabilité vs Immuabilité, Danger de l'Aliasing `L2=L1`, Tuples, Sets, Dictionnaires).

   - زر **Vérifier ma solution** للتحقق التلقائي من صحة الحل ومنح نقاط الخبرة (+50 XP).
   - زر **Indice** للتلميحات وزر **Solution** للحصول على الحل النموذجي.

## 🚀 طرق التشغيل (How to Run)

### 1. عبر التطبيق التنفيذي المباشر (Fichier Exécutable .exe):
التطبيق متوفر كملف تنفيذي جاهز يعمل بدون الحاجة لتثبيت بايثون:
- ستجده في المجلد: `dist/PythonProGuide.exe`
- فقط اضغط عليه نقرتين وسيفتح كنافذة سطح مكتب احترافية (Native Desktop App) مع سيرفر بايثون حقيقي مدمج!

### 2. عبر المتصفح مباشرة (Navigateur Web):
- اضغط نقرتين على ملف `index.html` وسيفتح مباشرة في أي متصفح ويب، أوفلاين بالكامل.

### 3. عبر سطر الأوامر (Python Local Server):
```bash
python main.py
```
